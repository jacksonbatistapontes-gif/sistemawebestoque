# Sistema Web de Controle de Estoque

Aplicação web simples para gestão de almoxarifado de construção civil. Permite cadastrar materiais, registrar entradas e saídas, acompanhar itens críticos e filtrar por categoria, local e status.

## Como usar

Abra o arquivo `index.html` no navegador ou sirva o diretório com qualquer servidor estático.

## Funcionalidades

- Dashboard com indicadores de estoque.
- Cadastro de materiais com unidade, fornecedor e níveis mínimos.
- Movimentações rápidas de entrada/saída.
- Filtros, menus e busca integrada.
- Persistência local via `localStorage`.
